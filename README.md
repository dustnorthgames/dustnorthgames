# Concrete Reign Website

A responsive promotional website for **Concrete Reign** by **Dust North Games**.

## Upload to GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the full `assets` folder.
3. Open the repository's **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then press **Save**.
7. GitHub will display the live website address after deployment.

## Editing text

Open `index.html` and replace any wording you want to change.

## Replacing images

Keep the filenames below, or update their paths in the HTML and CSS:

- `assets/concrete-reign-cover.png`
- `assets/dust-north-logo.png`

## Note

The artwork is labelled as concept art. Check any final game name and logo for existing trademarks before commercial release.
