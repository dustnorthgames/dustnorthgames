# Concrete Reign — GitHub Pages Website

A responsive promotional concept website for **Concrete Reign** by **Dust North Games**.

## Features
- Cinematic animated landing page
- Parallax artwork and moving neon glows
- Scroll reveal and staggered animations
- Animated headline ticker
- Interactive concept-art cards
- Concept teaser pop-up
- Live countdown to **March 23, 2027**
- Mobile menu and responsive design
- GitHub Pages ready

## Upload to GitHub Pages
1. Create or open your GitHub repository.
2. Upload `index.html`, `style.css`, `script.js` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your main branch and `/ (root)`, then press **Save**.

## Editing the planned pre-order date
Change this line in `index.html`:

```html
<div class="countdown" data-countdown="2027-03-23T00:00:00">
```

The page clearly states that pre-orders are not live and the planned date may change.
